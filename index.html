Install on your Samsung device
  1. Open this page in Samsung Internet or Chrome on the tablet or phone, using the address your computer printed (it starts with http://192.168 or similar).
  2. Tap Download APK. If asked, allow the browser to install apps from this source.
  3. Open the downloaded file and tap Install. If Play Protect warns about an unknown app, tap More details, then Install anyway.
  4. Open PalmSketch. Do the circle setup: stylus first, then your hand.
